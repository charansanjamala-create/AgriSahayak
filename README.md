# 🌱 AgriSahayak
**Smart Agricultural Advisory & Farmer Support Platform** *(🏆 2nd Prize Winner - Data Science Department Hackathon)*

### ✨ Key Features
- **Crop & Soil Advisory:** Data-driven crop recommendations and seasonal farming guidance tailored for farmers.
- **Pest & Disease Assistance:** Actionable preventive measures and treatment insights to protect crop yield.
- **Weather & Market Insights:** Real-time agricultural updates to help farmers plan harvesting and selling decisions.
- **Accessible Web Interface:** Clean, user-friendly dashboard designed for quick navigation and practical field usage.

### 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Backend & Data Science:** Python, Flask, Data Analytics
