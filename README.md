# 🌾 AgriSahayak — Your Digital Partner for Every Farming Problem

**AgriSahayak** is a complete, modern, professional AI-powered Agriculture Problem-Solving Platform built for Indian farmers across all states and landholding categories.

---

## ✨ Key Features & Capabilities

1. **20 Touch-Friendly Agricultural Problem Categories**:
   - 🌱 Crop Problem • 🐛 Pest / Insect Problem • 🦠 Crop Disease • 💧 Water & Irrigation
   - 🌧️ Weather Advisory • 🌾 Soil Management • 🌱 Seed Selection • 🧪 Fertilizer Guidance
   - 💰 Mandi Prices • 🏦 Farm Loans (KCC) • 🛡️ Crop Insurance (PMFBY) • 🚜 Machinery
   - 👨‍🌾 Government Schemes • 🧑‍🌾 Labour • 📦 Storage • 🚚 Transport • 🏪 Marketplace
   - 📚 Krishi Gyan Learning • 🤖 Conversational AI Assistant • 🚨 Emergency SOS

2. **Multimodal Problem Input**:
   - 📝 Multilingual Natural Text Input
   - 🎤 Native Indian Speech Recognition (Web Speech STT in 8 languages)
   - 📷 Crop Leaf Photo Capture & Computer Vision Disease Scanner
   - 🔊 Text-to-Speech (TTS) Read-Aloud for field hands-free listening

3. **8 Indian Languages Supported**:
   - English, Telugu (తెలుగు), Hindi (हिन्दी), Tamil (தமிழ்), Kannada (ಕನ್ನಡ), Malayalam (മലയാളം), Marathi (मराठी), Bengali (বাংলা)

4. **Conversational Diagnostic AI**:
   - Asks smart follow-up clarification questions
   - Generates structured 6-part actionable advisory reports
   - Quantified disease severity scoring with organic & safe chemical remedies

5. **Live APMC Mandi Prices & Trends**:
   - Real-time market comparison across nearby APMC yards
   - 7-day price trajectory graphs with Minimum Support Price (MSP) benchmarks

6. **Government Schemes Discovery Engine**:
   - PM-KISAN, PMFBY, KCC, PM-KUSUM, SMAM, Soil Health Card, Rythu Bharosa
   - Interactive eligibility checker & direct official portal links

7. **Farm Budget & Economics Calculator**:
   - Input costs, projected yield, gross revenue, net profit/loss, and ROI %

8. **Farm Machinery & Custom Hiring Centers (CHC)**:
   - Tractor HP sizing recommendations, implements catalog, and CHC hourly rental rates

9. **Direct Farmer-to-Buyer Marketplace (Kisan Bazaar)**:
   - Zero-commission produce listings and buyer demand leads

10. **Talk to Agricultural Scientists**:
    - Directory of certified university Agronomists, Pathologists, and Soil Scientists

11. **My Farm Dashboard & Stage-Wise Calendar**:
    - Active crops progress tracker, daily irrigation schedule, and problem ticket history

12. **Emergency SOS Response**:
    - 1-Click Dial to Toll-Free National Kisan Call Center (`1800-180-1551`)

## 🚀 Running the Project

### 1. Start the Backend API (Port 5000):
```bash
cd server
node server.js
```

### 2. Start the Frontend Web App (Port 5173):
```bash
cd client
npm run dev
```

### 3. Open in Browser:
Visit `http://localhost:5173` to explore the AgriSahayak platform!
